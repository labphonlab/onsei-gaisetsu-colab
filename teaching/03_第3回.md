# 第3回　音を書く — IPA・表記・音素

## 1　この回の到達点

　IPAの子音表から三つの指定を読み取れること。そして、音素と異音の区別を、日本語の「ん」の例で説明できること。

　後半の音素の話が、この科目で最も抽象的な内容である。**この回を落とすと第8章と第9章が理解できない。**時間配分は後半に厚くする。

## 2　時間配分

| 3.1 | 「ん」を四通り言い分ける | 12分 |
| 3.2 | 文字は音を写さない | 12分 |
| 3.3 | 子音表と母音四角形の読み方 | 15分 |
| 3.4 | 日本語をIPAで書いてみる | 13分 |
| 3.5 | 意味を変える違いと変えない違い | 20分 |
| 3.6 | どこまで細かく書くか | 10分 |
| — | まとめ・課題 | 8分 |

　**削ってよい節**は3.6である。表記の水準の話は、第12章5節で法廷の書き起こしを扱うときに実質的な形で再登場する。

## 3　準備するもの

　音源は不要。IPAの子音表と母音四角形を配布資料かスライドで用意する。付録Aの表を配ってもよい。

## 4　導入の手順

1. 「新聞」「案外」「安心」「パン」を板書する。
2. 一語ずつゆっくり発音させ、「ん」で止めさせる（2分）。
3. **止めた状態で「そのまま口を開けてください」と指示する。**「パン」だけ音が続き、他は続かないことに気づかせる。これが最も効果的な提示である。
4. 唇が閉じているか、舌がどこに触れているかを、四語について挙手で確認する。
5. 「四つとも『ん』と書くのに、なぜ違う音なのか。そして、なぜ日本語話者はこれを『同じ音』だと思っているのか」を板書し、後半で答えると宣言する。

## 5　各節で押さえること

**3.2.3**　韓国語の「독립」の例は、韓国語履修者がいると盛り上がる。いなければ日本語の「読む／読まない／読んで」に絞ってよい。要点は「表記は語の形を一定に保つほうを優先する」ことである。

**3.3.2**　子音表は**読み方だけ**を教える。暗記させない。「[t] を指してください」「このマスの音は何と呼びますか」という往復を数回行えば十分である。

**3.4.1**　サ行・タ行・ハ行の交替は、全員に「さしすせそ」「たちつてと」「はひふへほ」を発音させ、どこで舌が動くかを観察させる。**五十音図が音の表ではない**という気づきが、この節の核である。

**3.5.2**　この回の山場である。板書の順序を決めておく。

1. 四つの「ん」を書く
2. それぞれが現れる環境を書く（[p][b][m] の前、など）
3. 「ある環境に現れるものは別の環境には現れない」ことを矢印で示す
4. だから語の区別に使えない、と結論する
5. まとめて /N/ と呼ぶ、と導入する

　韓国語の「감／간／강」を対置すると、同じ違いが言語によって扱いを変えることが一目で分かる。

## 6　想定される反応と対応

**「異音と音素、どちらが本当の音か」**——両方とも実在するが水準が違う、と答える。異音は物理的な実在、音素は話者の頭のなかの単位である。5.2.3で述べた「単位は話者の振る舞いから推定される」という論法をここで先取りしてもよい。

**「相補分布かどうかはどう調べるのか」**——実際にデータを集めて環境を書き出す、と答える。未記述の言語の調査ではこれが最初の作業になる。

**「IPAを覚えないと単位が取れないか」**——覚えなくてよいと明言する。ただし、記号を見て三つの指定を言えることは求める、と条件を示す。

**「ミニマルペアが見つからないと音素と言えないのか」**——原則そうだが、例外的な扱いもあると答える。深入りは避ける。学部の入門では「ミニマルペアがあれば対立、相補分布なら異音」で十分である。

## 7　スライド用の要点

1. 実用的な表記は音を忠実に写さない。語の同一性の保持が優先されるからである。
2. IPAは一音一記号・言語非依存・記述の体系性という三原則で作られている。
3. 日本語をIPAで書くと、五十音図の行のなかで子音が交替していることが見える。
4. 意味を変える違いが音素、変えない違いが異音である。
5. どこに線を引くかは言語ごとに違う。同じ違いが、ある言語では対立、別の言語では異音になる。
