# 別冊音源　台帳

『音声学概説』精選版の各章の導入は、その場で音を聴く作業から始まる。
本書はその音源を別冊資料として配布する。本ファイルはその一覧と、
制作状況・権利処理の記録である。

生成済みの音源37点は `out/`、生成スクリプトは `scripts/gen_audio.py` にある。

```bash
python3 scripts/gen_audio.py          # すべて再生成
python3 scripts/gen_audio.py shepard  # 一部だけ
```


## 1　合成で制作済み（権利処理不要）

いずれも `scripts/gen_audio.py` が数式から生成する。外部素材を使っていないため、
配布・改変・授業での提示に制約はない。

| ファイル | 章 | 内容 | 検証済みの仕様 |
|---|---|---|---|
| `ch02_pero.wav` / `ch02_perro.wav` / `ch02_pero_perro.wav` | 2.5.2 | スペイン語のはじき音とふるえ音 | 閉鎖の数が1回対3回 |
| `ch04_aiueo.wav` | 4.1.1 | 「あいうえお」（スペクトログラム観察用） | 実測F1/F2＝あ820/1308、い339/2196、う353/1238、え526/1899、お517/855。いずれも設計値から40Hz以内 |
| `ch05_accent_*.wav` | 5.3.1 | 日本語アクセント3型（頭高・平板・尾高） | 頭高190→138Hz、平板134→190Hz、尾高132→190→139Hz（助詞で下降） |
| `ch05_tone_*.wav` | 5.4.1 | 中国語の四声 | 実測F0：第一声200一定、第二声146→211、第三声111→92→144、第四声199→115 |
| `ch05_viet_*.wav` | 5.4.2 | ベトナム語の平坦調と声門化を伴う調 | 平坦調150Hz一定、声門化調143→85Hzで後半がきしみ声に移行 |

**制作方法の限界。**フォルマント合成による音声は自然音声ではない。ただし
7.2.1で述べるとおり、カテゴリカル知覚の実験は元来この種の合成音を用いて
行われてきた。教室で「合成音だから区別できないのでは」という疑問が出た
場合は、これが実験の標準的な手続きであることを説明するとよい。


## 2　自前録音が必要（未制作）

著者または協力者の録音で用意する。第三者の権利は発生しない。

| 章 | 内容 | 要件 |
|---|---|---|
| 5.1.1 | 「そうですか」六通り | 同一話者。相槌・聞き返し・疑い・落胆・怒りの抑制・切り上げ。**態度の伝達は合成では作れない**（5.6.3で述べたとおり声質と間が関与するため） |
| 8.1.1 | 「ありがとうございます」速い発話 | 丁寧版と普段の速さの対で録る |
| 12.1.1 | 話者照合の演習用ペア | 同一話者の別場面録音と、別話者の類似録音 |
| 14.1.1 | （不要） | 商品名リストは紙で足りる |

　なお第4章1節の「あいうえお」は合成音源を用意したが、**教員が教室でその場で録音して分析するほうが望ましい**。自分の声が図になるという体験が、この節の要点だからである。合成音源は予備と位置づける。

**録音の仕様。**サンプリング周波数 44.1kHz 以上、16bit 以上、モノラル、
静穏な室内、口元から20〜30cm。第4章の測定に使うため、録音レベルは
クリッピングを避けて −12dBFS 程度を目安にする。


## 3　外部素材が必要（未着手・権利処理を要する）

| 章 | 内容 | 課題 |
|---|---|---|
| 9.1.1 | 年齢の異なる5話者（3・10・20・45・70歳）の同一文 | コーパスからの抜粋か、協力者の録音。子どもと高齢者の録音は同意の取得に配慮が要る |
| 11.1.1 | 訛りの強さと通じやすさが乖離する学習者音声2本 | 学習者音声コーパスからの抜粋。二次利用条件の確認が必要 |
| 12.1.1 | 出身・年代の異なる話者の音声クイズ（6本） | 同上。話者の同定可能性があるため、公開範囲の設定が要る |
| 13.1.1 | 合成音声と人間の声の判定テスト（8本） | 年代の異なる合成音声。**1970〜90年代の合成音は公開アーカイブに依存する。**現行の市販システムの出力は利用規約の確認が必要 |
| 7.4.1 | 音韻修復のデモ | 自然発話の一部を雑音で置換する。自前録音から作成可能だが、合成音では効果が弱い |
| 7.5.1 | マガーク効果の映像 | 映像が要るため音源のみでは成立しない。授業では既存の公開映像の提示が現実的 |

**第13章の音源についての注意。**13.1.2で述べるとおり、この判定テストは
合成音声の世代差を体験させるものである。現行システムの出力を含める場合、
「2020年代半ばの市販システム」という世代の明示が本文と対応している必要が
ある。更新の際は本文の記述も併せて改めること。


## 4　制作の優先順位

1. **第2節の自前録音**（5.1.1、8.1.1）——著者だけで完結し、該当章の導入が
   これなしには成立しない。
2. **第3節のうち13.1.1**——公開アーカイブの音源で大部分を賄える。
3. **第3節のうち9.1.1、11.1.1、12.1.1**——権利処理と同意取得に時間がかかる。
   代替として、教室で受講者自身の音声を使う手続きを授業補助資料に用意する。
4. **7.5.1のマガーク効果**——自前制作は困難。既存の公開映像を案内する。
